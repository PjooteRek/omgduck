OMG Dock

Polityka prywatności

Obowiązuje od 11 listopada 2026 r.

W skrócie: OMG Dock działa na Twoim komputerze. Nie ma konta, reklam ani śledzenia i nie wysyła twórcy żadnych Twoich danych. Gdy włączysz funkcję, która potrzebuje internetu (staty z gier, teksty piosenek, Steam), program pyta wprost odpowiednią usługę tylko o to, czego potrzebuje do wyświetlenia.

Co zostaje na Twoim komputerze

Wszystko, co program zapamiętuje, leży lokalnie w folderze danych OMG Dock (%LOCALAPPDATA%\OMG Dock, a w wersji z Microsoft Store w prywatnym folderze tej aplikacji):

  • ustawienia, w tym wpisane nicki, BattleTag, Riot ID i opcjonalne klucze API (FACEIT, Steam),
  • historia schowka (teksty, ścieżki plików i obrazki) – teksty oznaczone przez menedżery haseł nigdy nie są zapisywane, a historię możesz wstrzymać albo wyczyścić w ustawieniach,
  • notatki, wydarzenia z kalendarza docka, zapamiętane teksty piosenek i historia Twojego ELO.

Program czyta też lokalnie, bez wysyłania gdziekolwiek: odtwarzaną muzykę z Windowsa, powiadomienia Windows (jeśli na to pozwolisz), pliki Steama, uruchomionego klienta League of Legends, powtórki Fortnite i dane o sprzęcie (procesor, RAM, dyski). Korektor słucha dźwięku z głośników tylko wtedy, gdy jego paski są widoczne, liczy poziomy w pamięci i niczego nie nagrywa ani nie zapisuje.

Klip głosem, jeśli go włączysz, słucha mikrofonu i na Twoim komputerze rozpoznaje tylko kilka komend, takich jak „klipuj to”. Dźwięk jest analizowany w pamięci: nic nie jest nagrywane, zapisywane ani wysyłane.

Klipy w grach (włączone, dopóki nie wyłączysz ich w ustawieniach): tylko gdy gra jest na pierwszym planie, program trzyma w pamięci jej ostatnie sekundy (15–60, jak ustawisz) – obraz okna gry, dźwięk z głośników i, jeśli to włączysz, mikrofon. Starsze sekundy są na bieżąco nadpisywane, a po wyjściu z gry pamięć jest zwalniana. Plik powstaje wyłącznie wtedy, gdy zapiszesz klip (przyciskiem, skrótem albo głosem), w folderze Wideo\OMG Dock. Nic nie jest wysyłane.

Półka przesyła pliki między tym komputerem a telefonem albo drugim komputerem w Twojej sieci lokalnej, tylko gdy włączysz w niej udostępnianie. Pliki idą prosto między urządzeniami, bez żadnego serwera w internecie, a te odebrane trafiają do folderu Pobrane\OMG Dock. Jeśli w telefonie włączysz podgląd kamery, jej obraz jest przesyłany tą samą siecią lokalną i pokazywany na żywo na tym komputerze — nic nie jest nagrywane ani zapisywane.

Z jakimi usługami się łączy

UsługaCo dostaje i po co
FACEITNick, żeby pokazać ELO i poziom. Jeśli wpiszesz swój klucz API – także ten klucz, po K/D, ostatnie mecze i obrazki ich map.
OverFast APIBattleTag, żeby pokazać rangi Overwatch z publicznego profilu.
LRCLIB (lrclib.net)Tytuł, wykonawcę, album i długość utworu, żeby znaleźć tekst piosenki (wersja Pro).
SteamNumery gier (nazwy, okładki, nowości, bestsellery), publiczne profile ulubionych znajomych, a jeśli wpiszesz klucz Steam Web API – ten klucz i Twój SteamID, po liczbę gier na koncie.
Community DragonTylko numery ikon bohaterów League of Legends, żeby je wyświetlić.
Microsoft Store / SteamZakup wersji Pro obsługuje sklep; program tylko pyta system, czy Pro jest kupione.
GitHubWersja ze strony co kilka godzin sprawdza, czy jest nowa wersja OMG Dock, i pobiera jej instalator. Przy pierwszym włączeniu klipu głosem pobiera też silnik mowy Vosk. Nic nie jest wysyłane.
alphacephei.comTylko przy pierwszym włączeniu klipu głosem: pobranie modelu mowy (ok. 50 MB). Nic nie jest wysyłane.

Każda z tych usług ma własną politykę prywatności. Przyciski takie jak op.gg, FACEIT czy fortnitetracker.com tylko otwierają stronę w Twojej przeglądarce.

Czego program nie robi

  • nie zbiera statystyk użycia, nie ma reklam ani narzędzi śledzących,
  • nie wysyła twórcy ani nikomu innemu Twojego schowka, notatek, plików czy kluczy,
  • nie sprzedaje i nie udostępnia danych.

Usunięcie danych

Odinstaluj OMG Dock i usuń folder danych. Historię schowka możesz też wyczyścić w ustawieniach (Schowek → Wyczyść historię), a klucze API usunąć w Ustawieniach → Gry i konta.

Privacy policy – English summary

OMG Dock runs on your PC. It has no account, ads, analytics or tracking, and sends no personal data to its developer. Settings, clipboard history (password-manager entries are never stored), notes and caches stay in the local data folder. Only when a feature needs it does the app contact a third-party service directly: FACEIT (nickname, and your own API key if you add one), OverFast API (BattleTag), LRCLIB (song title, artist, album, length), Steam (app IDs, public profiles of favourite friends, and your Steam Web API key and SteamID if you add a key) and Community Dragon (League of Legends icon IDs). The equalizer analyses speaker output in memory and records nothing. Clip by voice, if you turn it on, listens to the microphone and recognises a few commands on your PC; the audio is processed in memory and never recorded, saved or sent. For clips in games (on unless you turn them off in the settings), only while a game is in front it keeps the game's last seconds in memory (its window, the speakers' sound and, if you turn it on, the microphone); a file is written only when you save a clip, to Videos\OMG Dock, and nothing is sent. While you have sharing on, the shelf swaps files directly with a phone or another computer on your local network, with no server in between; received files are saved in Downloads\OMG Dock. If you turn on the phone's camera, its picture streams over the same local network and shows live on this PC; nothing is recorded or saved. The website version checks GitHub for new versions and downloads them; turning on clip by voice downloads the Vosk speech engine from GitHub and a speech model from alphacephei.com once. Purchases are handled by the Microsoft Store or Steam. To remove your data, uninstall the app and delete its data folder. Contact: github.com/PjooteRek/omgduck/issues.
